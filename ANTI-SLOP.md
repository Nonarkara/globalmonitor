# Design entry point

Read `.non-slop/AGENTS.md` before interface work and `STYLE.md` for this product's deliberate identity. Those choices are protected; a generic reskin is not a repair.

The map is the operating table. Keep chrome compact, controls reachable, data qualified with source and age, and all earned content accessible. Test intermediate CSS breakpoints and open drawers, not only preset screenshots.

Run `npm run design:check` and `npm run verify:live -- <deployed HTTPS URL>`. Inspect the screenshots and obtain an independent review. A source scan is not a visual verdict.
